# JUI SSURI Portfolio

Static portfolio for GitHub Pages.

## Structure

- `index.html` — main portfolio
- `portfolio.html` — fast-navigation shell and persistent audio player
- `project-view.html` — full-screen project preview
- `project-breakdown.html` — project process and details
- `css/` — stylesheets
- `js/` — client-side behavior
- `assets/audio/` — soundtrack
- `assets/fonts/` — local web fonts
- `assets/icons/` — software icons and source notes
- `assets/images/` — optimized portfolio images

## Local preview

```sh
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/` in a browser.
